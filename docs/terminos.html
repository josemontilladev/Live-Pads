Última actualización: 27 de mayo de 2026

Estos Términos regulan el uso de LivePads ("la aplicación", "el servicio"). Al crear una cuenta o usar la aplicación, aceptas estos Términos. Si no estás de acuerdo, no uses el servicio.

1. El servicio

LivePads es una aplicación de escritorio para reproducción de pads, metrónomo, edición de stems y gestión de repertorio para directo, con una opción de cuenta en la nube para sincronizar y compartir librerías. La aplicación puede usarse en modo local (sin cuenta) o con cuenta.

Conservas todos los derechos sobre el contenido que subes (canciones, letras, listas, configuración). Nos concedes únicamente la licencia técnica necesaria para almacenarlo, sincronizarlo y mostrarlo a ti y a las personas que invites a tus librerías, con el fin de prestar el servicio.

Eres responsable de tener los derechos necesarios sobre el contenido que subas (por ejemplo, letras o material protegido por derechos de autor). No subas contenido ilegal o que infrinja derechos de terceros.

4. Uso aceptable
